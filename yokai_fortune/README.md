# 百鬼夜行モード（試作）

鬼版とは別に保管する、第二弾の妖怪占いプロトタイプです。まだ公開URL・決済・鬼版からの導線はありません。

## 起動

リポジトリのルートで、既存の仮想環境を使って起動できます。

```bash
python yokai_fortune/app.py
```

`http://127.0.0.1:5050` を開いてください。

## 方針

- 鬼版の荒々しい口調と分け、夜・静けさ・不気味さを軸にする
- 無料版は12妖怪から一体を読む
- 反応が取れたら「百鬼夜行」として有料版・相性・夜ごとの予告を追加する
- 本番公開時に独立Renderサービスまたは別リポジトリへ分離する
